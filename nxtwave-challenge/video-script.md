## Pro-Tips for Recording Your Video

1. **Screen Recording Tool:** Use **OBS Studio** or **Loom** (free). Select 1080p recording at 60fps.
2. **Audio Quality:** Use wired earphones with mic or a basic lapel mic. Speak with clarity and steady pacing.
3. **App State Before Recording:**
   - Make sure your local server is running (`npm run dev` at `http://localhost:3000`).
   - Start with **Simulation Demo Mode ON** so the numbers and counters on the dashboard look vibrant.
   - Keep the demo tab open and test clicking the buttons once beforehand.
4. **Time Constraint:** Keep the final video between **2:45 and 3:05 minutes**. Going under 2:30 feels rushed; going over 3:15 violates the challenge limit.
