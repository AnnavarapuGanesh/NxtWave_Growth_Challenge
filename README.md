## 🌟 Executive Summary

This repository contains my submission for the NxtWave Growth Intern Challenge.

The objective was to design a practical 7-day growth strategy to acquire **500 final-year engineering student registrations** for the **"Build Your First AI Project in 60 Minutes"** workshop with a total budget of **₹2,000**.

Instead of building only a static landing page, I created a **Referral-Powered Registration Engine** that supports student registration, referrals, AI project discovery, WhatsApp outreach, and campaign tracking.
